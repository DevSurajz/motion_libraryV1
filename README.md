# Lumen — Next.js

Next.js 15 App Router port of the Lumen single-file site.

Stack: TypeScript, Tailwind CSS v4, Radix (Dialog, Accordion, Tabs, Slot) shadcn-style, framer-motion (reveals, intro), react-three-fiber (hero shader), Lenis (smooth scroll), cmdk (⌘K palette).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

Routes: `/`, `/library`, `/layer/[slug]` (50 statically generated), `/pricing`, `/docs`, `/contact`.
